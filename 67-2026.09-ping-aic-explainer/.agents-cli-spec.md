# Agent Spec

## Overview

Coordinator agent that explains PingOne Advanced Identity Cloud using public
docs. It stays concise on Ping product questions, and only expands generic IAM
terms (OAuth, SSO, SAML, …) when the user asks or says they are a beginner.

## Example Use Cases

- “What is journeys in PingOne AIC?” → short Ping-scoped answer.
- “I’m a beginner, what is OAuth?” → terminology specialist plus a blog link.

## Tools Required

- Google Search (built-in), wrapped in dedicated search agents.
- URL context (built-in), wrapped in dedicated URL agents.
- Sub-agents: `pingone_aic_specialist`, `terminology_explainer`.

## Constraints & Safety Rules

- Do not lecture on generic IAM terms unless asked.
- Terminology specialist refuses topics outside IAM / digital identity.
- No GCP project numbers or resource IDs in source or committed config.

## Success Criteria

- Local playground answers Ping AIC questions from public documentation.
- `task test` passes without calling a live model.
- `agents-cli deploy` to Agent Runtime is the supported production path.

## Reference Samples

- Agent Studio export (`adk-ping-aic-explainer.py`) — multi-agent + AgentTool
  wrapping of built-in search/URL tools.
- agents-cli `adk` template 1.6.1 — `App`, FastAPI serving, Agent Runtime
  container deploy.
